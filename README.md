# Remote Control Bridge

Remote Control Bridge 是一个面向 Codex 和本地 Agent 的远程 SSH 工作台。它只监听本机回环地址，通过用户明确授权的 SSH 会话提供服务器状态、命令执行、任务观察和 SFTP 文件管理。

它不会保存 SSH 密码，不会监听公网端口，也不会要求在远端服务器安装常驻程序。

## 核心功能

### 远程会话

- 支持临时密码和 Ed25519 私钥认证
- 首次连接时显示并确认 SSH 主机指纹
- 浏览器刷新或关闭后，可通过仅浏览器持有的恢复凭证找回仍然有效的会话，不依赖 Agent 授权
- 使用 SSH 协议保活维持空闲连接，不因网页或 Agent 暂时无操作而自动断开
- 用户主动断开、连接持续失联或 Session 服务退出时清理会话
- Bridge、Session 和 Control 分离，减少单个服务重启的影响

### 主机状态

- 主机名、在线时间和系统负载
- CPU、内存和磁盘使用情况
- NVIDIA GPU 利用率、显存和温度
- 状态采集失败时保留其他可用信息

### 命令与终端

- 异步执行远程命令
- 实时读取标准输出和错误输出
- 支持超时、取消和输出大小限制
- 每个 SSH 会话最多使用四个可复用终端槽位
- 浏览器与 Agent 共用同一套会话和任务状态

### 持久任务

- 长时间任务与浏览器、Agent 观察过程分离
- 创建后立即返回任务 ID
- 支持断开后重新发现任务、按偏移继续读取日志
- 支持状态对账、取消、固定和历史记录
- 本地索引与远端任务记录都有容量和清理边界
- 不理解或接管训练、模型、数据集和 checkpoint 等业务语义

持久任务是显式启用的增强功能。任务能否在 SSH 注销或本机断联后继续运行，取决于远端可用的启动器和系统策略；系统会区分可靠持久化与尽力模式。

### 文件管理

- 使用 SFTP 浏览远程目录
- 上传到当前打开的文件夹
- 支持续传、暂停、继续、取消和删除传输记录
- 下载、重命名、新建目录，以及删除文件或空目录
- 上传同名文件前询问是否覆盖
- 支持图片和受限文本预览
- 二进制文件及大文件默认不进入网页预览
- 拦截 `.ssh`、私钥、凭据和 `.env` 等敏感路径

### Agent 能力

本地 Agent 只有在用户明确授权后才能发现当前 SSH 会话。授权按主机、端口、用户名和 SSH 指纹绑定，并带有作用域和有效期。

只要 SSH 会话仍然存活且用户没有关闭 Agent 权限，Session 会自动滚动续期授权，不设置累计时长上限。用户关闭 Agent、主动断开连接、SSH 失联或 Session 退出时停止续期，并撤销当前授权。

Agent 可以：

- 读取会话和主机状态
- 提交、观察和取消受限命令
- 读取目录、文件预览、图片和下载内容
- 读取指定日志
- 在启用后管理 Bridge 自己的持久任务记录

Agent 默认不能上传、编辑、重命名或删除普通远程文件，这些操作保留在浏览器中由用户直接确认。

## 平台范围

- 本机 Bridge 使用 Node.js 跨平台运行时，面向 Windows、Linux 和 macOS。
- Windows 提供 PowerShell 管理包装；其他平台使用通用 Node.js 管理入口。
- 远端基础 SSH 和 SFTP 面向 POSIX 路径。
- 主机监控和持久任务当前主要面向 Linux，依赖 `/proc`、Bash 和经过探测的后台启动工具。
- 远端 Windows 目前不属于完整支持范围。

## 安全边界

- 所有本地服务只绑定 `127.0.0.1`
- 拒绝不受信任的 `Host` 和 `Origin` 请求
- SSH 密码只用于连接握手，不写入配置、日志或磁盘
- 浏览器恢复凭证使用 `HttpOnly`、`SameSite=Strict` 的本机 Cookie，Session 只保存哈希并绑定 SSH 指纹；主动断开后立即失效
- 主机指纹必须由用户确认，不自动信任未知主机
- 命令、输出、预览、上传和日志读取都有上限
- Agent 授权可以立即撤销
- 远端任务记录与用户代码、输出、权重和数据集相互隔离
- 故障测试使用本地模拟和临时资源，不破坏真实远端环境

Bridge 提供的是本机授权和误操作防护，不替代远端操作系统本身的账号权限、审计和安全策略。
