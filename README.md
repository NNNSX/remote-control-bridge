# Remote Control Bridge

Remote Control Bridge 是一个只监听本机回环地址的 SSH/SFTP 代理。它让浏览器和本地 Agent 共用用户明确授权的 SSH 会话，不要求在远端安装常驻程序，也不保存 SSH 密码。

## 核心能力

- SSH 密码或私钥连接、主机指纹确认、协议保活
- 浏览器恢复仍存活的本地会话
- 远程命令执行、输出读取、取消和终端状态查询
- SFTP 目录浏览、下载、上传、写入、建目录、重命名和删除
- 图片预览，以及受限文本预览；二进制文件交给下载或远程工具处理
- 本地 Agent 通过授权后的当前 SSH 会话调用状态、命令和 SFTP 接口

## 可选增强

持久任务、后台任务观察、任务日志和主机状态面板属于可选增强。它们只负责启动、观察和查询通用远程任务，不理解训练、模型、数据集、checkpoint 或其他项目语义。任务是否能在 SSH 会话之外继续运行，完全取决于远端已有的 shell、进程组和系统策略。

## 文件与权限

Agent 使用 `files:read` 读取文件，使用 `files:write` 直接调用文件写入、上传、建目录、重命名和删除接口。桥接层不增加文件大小、覆盖或远端权限规则；具体行为由远端 SFTP/SSH 服务返回。仅保留本机回环绑定、路径穿越校验和必要的响应流式处理。

## 安全边界

- Control、Session、Bridge 只绑定 `127.0.0.1`
- 未知 SSH 主机指纹必须由用户确认
- 密码只用于建立连接，不写入配置、日志或任务记录
- Agent 授权绑定主机、端口、用户名和已确认的 SSH 指纹，并可立即撤销
- 可按 SSH 会话启用受控的远端回环 SOCKS5 转发，供明确标记的远程命令临时使用
